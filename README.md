# NexHire

NexHire is an AI-powered campus recruitment and placement platform for students, colleges, and recruiters.

## Current status

Phase 0 provides a React/Vite/Tailwind foundation, polished student dashboard demo, React Hooks experiment integration, and minimal Express health API. Authentication and business modules start in later phases.

## Stack

- React, Vite, Tailwind CSS, React Router DOM, Axios, React Hook Form, Recharts
- Node.js, Express, dotenv, CORS, Helmet

## Local setup

1. Copy each .env.example file to .env.
2. Run npm install in client and server.
3. Run npm run dev in both directories.
4. Visit the Vite URL and verify http://localhost:5000/api/health.

## Structure

client is the React SPA, server is the Express foundation, and docs contains the approved architecture and implementation plan.
